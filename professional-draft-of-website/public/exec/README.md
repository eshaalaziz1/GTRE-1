# Executive board headshots

Drop each person's **square headshot** in this folder, named exactly as listed
below (all lowercase, `.jpg`). The Leadership page (`/leadership`) loads them
automatically — no code change needed. Until a file is here, that person shows a
clean initials avatar instead.

Square images look best (they're cropped to a circle). ~600×600px is plenty.
